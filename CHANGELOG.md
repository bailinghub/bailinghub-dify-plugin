# Changelog

All notable changes to this independent adapter are documented here.

## [Unreleased]

## [0.1.1] - 2026-07-21

### Changed

- Reduced the distributable package to runtime and Marketplace-required files.
- Clarified source, support, privacy, and Marketplace distribution boundaries.
- Added an automated package-content audit for forbidden development state and executables.

## [0.1.0] - 2026-07-21

### Added

- Dify tools for submitting, reading, and bounded-waiting on BailingHub jobs.
- Dedicated Client Token validation without exposing privileged APIs.
- Strict HTTPS, input, response-size, and error-sanitization boundaries.
- Independent project, compatibility, privacy, and release documentation.
