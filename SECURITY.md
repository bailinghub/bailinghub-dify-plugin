# Security Policy

Do not report credentials, private URLs, customer data, or production request bodies in a
public issue.

Use this repository's private GitHub Security Advisory channel for vulnerabilities. For
ordinary hardening ideas that contain no sensitive evidence, open a public issue with a
minimal reproducible example.

Supported releases are listed in `docs/COMPATIBILITY.md`. Test integrations with dedicated,
route-limited clients and harmless routes before using the adapter for business actions.
