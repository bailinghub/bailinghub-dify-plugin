# Security Policy

Do not report credentials, private URLs, customer data, or production request bodies in a
public issue.

When the public repository is available, use its private GitHub Security Advisory channel
for vulnerabilities. For ordinary hardening ideas that contain no sensitive evidence, open
a public issue with a minimal reproducible example.

Supported releases are listed in `docs/COMPATIBILITY.md`. Until the first public release,
this project is pre-release software and should be tested only with dedicated, route-limited
clients and harmless routes.
